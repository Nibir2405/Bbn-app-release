# 🩸 Bhangura Blood Network (BBN) - Official App Releases

Welcome to the official release distribution repository for the **Bhangura Blood Network (BBN)** Android application. This repository serves as the secure distribution hub where our latest production-ready APK builds are published for community members, donors, and patients.

---

## 📱 About the App
The **BBN Mobile App** is a high-performance, executive-themed platform designed to streamline emergency blood coordination in Bhangura and surrounding regions. 

### Key Features:
* **🚀 Instant Emergency Requests:** Patients and families can broadcast urgent blood needs directly into the network.
* **🟢 Donor Dashboard & Availability:** Registered donors can log in securely via Telegram OTP, view their 90-day cooldown status, and toggle their availability (*Ready / Busy*).
* **🌐 Bilingual Support:** Fully localized in both English and Bengali.
* **✨ High-End UI/UX:** Features a custom medical blood bag filling animation transitioning into the official BBN identity, built for maximum speed and reliability.

## 📥 How to Download & Install

You can download the latest stable version of the app directly from our releases:

1. Go to the **[Releases](../../releases)** section on the right sidebar (or scroll down to the **Latest Release** section).
2. Download the latest `.apk` file (e.g., `bbn-app-v1.0.x.apk`).
3. Open the downloaded file on your Android device and tap **Install**. 
   *(Note: If prompted by Android Security / Play Protect, allow installation from your file manager or browser as this is an official independent community release).*
